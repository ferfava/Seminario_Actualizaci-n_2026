# Clase 6 · Revisión de pares

## Consigna

Revisar en modo solo lectura el repositorio asignado de un compañero o compañera, analizarlo sin explicación adicional y publicar en el foro el enlace del repositorio, la rúbrica completada y un problema concreto encontrado.

## Repositorio revisado

https://github.com/lagabyok/seminario_de_actualizacion

## Revisión

La estructura por clases está creada y todas las carpetas tienen README. La Clase 02 posee documentación, un script ejecutable y evidencia del trabajo realizado. El repositorio también presenta historial de commits.

## Problema concreto encontrado

En `Clase_03`, `Clase_04` y `Clase_05` los README mantienen contenido de plantilla y no se encuentran archivos de código o recursos que permitan reproducir las actividades de esas clases. Esto dificulta entender qué se hizo sin una explicación adicional de la autora.

## Sugerencia de mejora

Completar cada README con el objetivo, los archivos utilizados, las instrucciones de ejecución y el resultado de la actividad, e incorporar el código correspondiente cuando aplique.

## Modalidad de revisión

La revisión se realizó en modo solo lectura. No se modificó ningún archivo del repositorio ajeno.
